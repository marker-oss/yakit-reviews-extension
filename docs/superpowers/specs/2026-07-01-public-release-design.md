# Публичный релиз Reviews (self-host) — дизайн

Дата: 2026-07-01
Ветка кода: `feat/legal-mitigation` (актуальный HEAD, впереди `main` на 64 коммита)

## Цель

Открыть репозиторий `marker-oss/yakit-reviews-extension` публично так, чтобы
**первые пользователи могли поставить сервис у себя по документации**. Минимально
и безопасно — без утечки внутренней истории разработки и внутренних данных.

## Не-цели (YAGNI)

- Демо-режим / публичный онлайн-стенд — **не делаем** (решение: только self-host
  по доке).
- SaaS-многотенантность, универсализация за пределы Яндекс Кит — вне объёма.
- Автодеплой прод-инфраструктуры — вне объёма этого релиза.

## Зафиксированные решения

1. **Try-path:** только self-host по документации. Демо нет.
2. **Публикация:** тот же репозиторий (`marker-oss/yakit-reviews-extension`),
   приватный → публичный. URL сохраняется, поэтому ссылки в `install.sh` и
   `release.yml` остаются валидными.
3. **История:** перед публикацией **переписать историю в один чистый
   orphan-коммит** (squash всех 66 коммитов). Публичный код = снимок актуального
   дерева (`feat/legal-mitigation` HEAD, консолидированного в `main`).
4. **Бэкап истории:** до перезаписи обязательно сохранить приватную историю —
   тег `pre-public-2026-07-01` + `git bundle` (локально/в приватное зеркало).
   Иначе dev-история теряется безвозвратно.
5. **Скриншоты:** обновлены и дополнены (готово — см. ниже).

## Известные ограничения (задокументировать в README перед релизом)

- **Q&A (F3):** имена полей questions-API для WB/Ozon выведены по догадке
  (доки были недоступны). Fetch вопросов из МП — экспериментальный; для Ozon
  тумблер по умолчанию выключен. Стоит отметить как «beta» в доке.
- **Каталог товаров:** дискавери заточен под Яндекс Кит (обход sitemap +
  regex по артикулу). Для других платформ потребуется доработка.

## Гейты и риски

- **Гейт 1:** весь код и тесты зелёные до перезаписи истории.
- **Гейт 2:** ничего не пушим в публичный remote, пока не пройден grep-аудит и
  пользователь глазами не просмотрел финальное дерево.
- **Гейт 3:** flip видимости и тег релиза — ручные шаги пользователя.
- **Риск:** перезапись истории в том же репо необратима для dev-истории →
  снимается обязательным бэкапом (п. 5). Приватный репо форков не имеет,
  старые коммиты станут недостижимы.
- **Риск:** `shegida` в 23 исторических коммитах → снимается squash'ем (история
  исчезает целиком).
