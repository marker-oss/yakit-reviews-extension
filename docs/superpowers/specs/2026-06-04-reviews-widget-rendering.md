# Reviews — прототип отрисовки виджета

**Дата:** 2026-06-04 · **Статус:** frontend prototype

Прототип находится в [`web/reviews-widget`](../../../web/reviews-widget).
Он сделан без npm/build step: обычные `demo.html`, CSS и JS.

## Режимы

- `demo.html` — статический mock-режим без backend.
- `dynamic.html` — динамический режим: виджет делает `fetch("/api/reviews")`
  и отрисовывает отзывы из SQLite.

Запуск динамического режима:

```sh
REVIEWS_DB_DSN=./reviews-e2e.db go run ./cmd/reviews serve --addr 127.0.0.1:8080
```

После запуска:

- виджет: `http://127.0.0.1:8080/dynamic.html`
- API: `http://127.0.0.1:8080/api/reviews?limit=100`

Для ссылки на карточку товара в магазине продавца используется шаблон:

```sh
REVIEWS_SITE_PRODUCT_URL_TEMPLATE="https://shegida.ru/search?query={seller_article_url}"
```

Поддерживаемые placeholders:

- `{article}` — артикул продавца, если он известен, иначе внешний ID товара;
- `{seller_article}` — артикул продавца из маркетплейса/каталога;
- `{seller_article_url}` — URL-escaped артикул продавца для query string;
- `{external_product_id}` — внешний ID товара маркетплейса;
- `{external_product_id_url}` — URL-escaped внешний ID товара;
- `{marketplace}` — `wb`, `ym`, `ozon`.

Перед шаблоном сервер проверяет JSON-карту точных ссылок:

```sh
go run ./cmd/reviews discover-site-urls --out data/shegida-product-links.json
```

Команда читает `https://shegida.ru/sitemap.xml`, открывает опубликованные
карточки `/products/...`, вытаскивает `sku` из JSON-LD и сохраняет пары
`sellerArticle -> url`. Для WB-артикулов вида `3467/Белый` API сначала ищет
точное совпадение, затем базовый артикул до `/`, например `3467`.

Если карточка не найдена в sitemap shegida.ru, `sellerProductUrl` остается
поисковой ссылкой по артикулу продавца. На текущем снимке сайта discovery
нашел 50 уникальных SKU; для тестовой БД это дает точные `/products/...` ссылки
для 135 из 262 отзывов, остальные отзывы корректно используют search fallback.

## Что показывает прототип

- Сводку по среднему рейтингу и количеству отзывов.
- Фильтр по маркетплейсу.
- Фильтр по оценке.
- Сортировку: новые, высокая оценка, низкая оценка, сначала с медиа.
- Карточки отзывов с автором, датой, рейтингом, текстом, плюсами/минусами.
- Два товарных идентификатора: `Артикул продавца` и `Артикул WB/Ozon/ЯМ`.
- Фото/видео-медиа как кликабельные превью.
- Ответ продавца, если он был импортирован из маркетплейса.
- Responsive layout для desktop/mobile.
- Переход из отзыва на карточку/отзывы товара на маркетплейсе.
- Переход по артикулу на карточку товара в магазине продавца.
